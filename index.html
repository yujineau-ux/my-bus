기사 로그인

운행을 시작한 기사만 위치 공유를 활성화할 수 있습니다.

운행 시작을 누른 동안에만 현재 위치가 공개 지도에 표시됩니다.

내 지도

로그인하면 자주 타는 노선과 탑승 위치를 이 기기에서 저장할 수 있어요.

위치 사용은 ‘내 현재 위치’ 버튼을 눌렀을 때만 요청되며, 위치는 이 기기에만 저장됩니다.

GPS 연결이 필요해요

위치 권한을 허용하면 현재 위치를 지도에 표시할 수 있습니다.

연결하는 방법
  1. 위치 권한 창이 뜨면 허용을 선택하세요.
  2. 권한 창이 다시 안 뜨면 주소창 왼쪽의 자물쇠 또는 사이트 설정에서 위치: 허용으로 바꾸세요.
  3. 휴대폰은 설정에서 위치 서비스를 켜고, Safari 또는 사용 중인 브라우저의 위치 권한을 허용으로 바꾸세요.
  4. 아래 버튼을 눌러 다시 연결해 보세요.

현재 위치는 지도에 표시할 때만 사용되며, 이 기능으로 저장되지 않습니다.
